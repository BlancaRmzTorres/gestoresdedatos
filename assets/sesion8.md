# Base de Datos para la Toma de Decisiones

## Introducción

Actualmente las organizaciones generan grandes volúmenes de datos provenientes de ventas, clientes, sistemas administrativos, dispositivos móviles, redes sociales y sensores. Sin embargo, tener datos no garantiza obtener información útil.

Para convertir los datos en conocimiento que apoye la toma de decisiones se utilizan herramientas y técnicas como:

- Data Warehouse
- Data Mart
- Data Mining
- Business Intelligence (BI)
- Machine Learning

## 1. Data Mart

### ¿Qué es un Data Mart?

Un Data Mart es un subconjunto especializado de un Data Warehouse diseñado para satisfacer las necesidades de análisis de un área específica del negocio.

### Ventajas

- Mejor rendimiento.
- Facilidad de uso.
- Seguridad.
- Menor complejidad.
- Mayor productividad.

### Desventajas

- Redundancia de información.
- Mayor mantenimiento.
- Riesgo de inconsistencia.
- Costos adicionales.

# 2. Data Mining

## Definición

Data Mining es el proceso de descubrir patrones, tendencias y relaciones ocultas dentro de grandes conjuntos de datos.

## Metodología CRISP-DM

1. Comprensión del Negocio.
2. Comprensión de los Datos.
3. Preparación de los Datos.
4. Modelado.
5. Evaluación e Implementación.

## Técnicas de Data Mining

### Clasificación
Predice categorías.

### Regresión
Predice valores numéricos.

### Clustering
Agrupa elementos similares.

### Reglas de Asociación
Encuentra productos comprados juntos.

### Detección de Anomalías
Identifica comportamientos inusuales.

## Caso Práctico: Market Basket Analysis

La asociación más común suele identificar productos que se compran juntos, permitiendo optimizar promociones, distribución e inventarios.

# Conclusiones

- El Data Mart organiza información especializada.
- El Data Warehouse integra datos corporativos.
- Data Mining transforma datos en conocimiento.
- CRISP-DM proporciona una metodología estructurada.
- Los datos generan valor cuando apoyan la toma de decisiones.
