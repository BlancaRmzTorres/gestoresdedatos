# Datos del proyecto ATUS 2025

Esta carpeta está destinada a los datos originales y procesados del proyecto.

- `raw/`: datos originales descargados del INEGI.
- `processed/`: datos limpios y preparados para el análisis y la carga en MongoDB.

Antes de publicar archivos de datos, se debe verificar su tamaño y las condiciones de distribución de la fuente.
